This appendix complements the main manuscript by providing detailed analytical, implementation, protocol, and supplementary evaluation material. It establishes the battery-free node models for energy harvesting and storage, intermittent operation, task execution, and communication energy. It further details the sampling-free energy monitor, MDSM indicator normalization and entropy-weight calculation, the reusable atomic cryptographic library, and the HEDA/DVFS control mechanisms. In addition, it specifies the message flows, verification procedures, assumptions, and security analyses for the LMAP, LPUFA, and E\textsuperscript{2}HA protocols, and reports supplementary task-level and sensitivity results. These details provide the theoretical, algorithmic, and implementation context for the design and evaluations presented in the main manuscript.
